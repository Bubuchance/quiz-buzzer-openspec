# 04 人工驗證清單

## 準備
- [ ] 依 README 安裝並執行 `python -m app.main`，終端機顯示網址與老師通行碼
- [ ] 執行 `python -m pytest`，全部通過
- [ ] 依 README「設定 Google Sheets 串接」建立服務帳號，金鑰放在 `credentials/service-account.json`
- [ ] 執行 `git status`，確認 `credentials/` 沒有出現在待 commit 清單（金鑰不進 repo）
- [ ] 老師頁顯示「請把試算表共用給 xxx@…iam.gserviceaccount.com」

## 身分（participant-access）
- [ ] 錯誤通行碼 → 顯示「通行碼錯誤」
- [ ] 正確通行碼 → 進入老師控制台
- [ ] 學生名字留空 → 顯示「請輸入名字」
- [ ] 分頁 B 加入第 1 組、分頁 C 加入第 2 組；老師頁「各組成員」出現兩人
- [ ] 重新整理學生分頁，仍是原本的組別與名字
- [ ] 老師把組數改成 6 → 新開的加入頁可選到第 6 組

## Guided Notes（guided-notes，直接讀寫雲端 Google Sheets）
- [ ] 老師範本「單題範例」「題組範例」各「檔案 → 建立副本」到自己的雲端硬碟
- [ ] 副本**還沒共用**給服務帳號就匯入 → 顯示「沒有權限：請…加為編輯者」
- [ ] 共用給服務帳號（編輯者）後貼網址匯入 → 單題範例 6 題、題組範例 4 題（第 1、2 題為題組）
- [ ] 在 Google Sheets 把標題列往下移幾列、把作答欄搬到別的位置 → 重新匯入仍正確（證明非固定位置）
- [ ] 貼上錯誤網址（例如 https://example.com）→ 顯示「請貼上 Google Sheets 網址」
- [ ] 匯入一份沒有「題號」「作答」標題的 Google Sheets → 顯示錯誤，原題目不變
- [ ] 把金鑰檔暫時改名再重啟 → 老師頁顯示「尚未設定 Google 服務帳號」（測完改回來）

## 搶答（buzzer-activity、live-sync）
- [ ] 尚未匯入與已匯入、還沒開始時，所有頁面都顯示「準備中」
- [ ] 開啟搶答前學生的作答欄是灰色不能輸入
- [ ] 老師按「開啟搶答」→ 兩個學生分頁幾乎同時變「搶答中」
- [ ] 第 2 組先送第 1 題、第 1 組後送 → 老師頁第 1 題顯示第 2 組成功、第 1 組順位 2
- [ ] 第 1 組分頁上**看不到**第 2 組的任何答案或送出狀況
- [ ] 學生頁顯示「本組已送出 N / 總題數」，別組送出時數字不變
- [ ] 同一組另開一個分頁（同組另一位成員）→ 看得到本組已送出的答案；再送同一題被拒絕
- [ ] 送出空白答案被拒絕；題組只填一格被拒絕
- [ ] 老師按「結束搶答」→ 學生頁同步顯示結果與各組成功題數；作答欄消失
- [ ] 結束後學生再送出（例如用另一個未送出的題）→ 不可能／被拒絕

## 匯出（guided-notes、result-reporting）
- [ ] 搶答中「寫回 Google Sheets」按鈕是灰色不能按
- [ ] 結束後按「寫回 Google Sheets」→ 雲端試算表：單題作答格出現成功答案、題組格出現「（1）答案」、沒人答的單題是空白，其他內容與格式不變
- [ ] 寫回後在同一份試算表再匯入一次 → 題數與題組不變
- [ ] 匯入後在 Google Sheets 刪掉一題，再按寫回 → 系統拒絕並請重新匯入
- [ ] 匯出 CSV → 用 Excel 打開中文正常，欄位：題號、組別、答案、搶答順位、是否搶答成功、送出時間

## 公平模式（額外功能）
- [ ] 按「重設」，勾選公平模式、延遲量 3 秒並儲存
- [ ] 讓第 1 組先搶下 2 題；之後某題第 1 組先送、第 2 組在 6 秒內送 → 第 2 組成功（結果顯示第 1 組「有效 X 秒」）
- [ ] 同上但第 2 組超過 6 秒才送 → 第 1 組成功

## 創意功能
- [ ] 設定搶答時限 30 秒 → 開啟後老師與學生頁都顯示倒數；時間到所有頁面自動變「已結束」
- [ ] 時限設為 0 → 不顯示倒數，需手動結束
- [ ] 搶答中結果表沒有「對／錯」按鈕；結束後出現
- [ ] 把某題標「對」→ 計分板該組得分 +1，學生頁同步顯示；改標「錯」→ 得分 -1；再按一次取消標記
- [ ] 按「重設」→ 標記與得分清空
