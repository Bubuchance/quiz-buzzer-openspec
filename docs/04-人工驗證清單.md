## 準備
- [ ] 依 README 安裝並執行 `python -m app.main`，終端機顯示網址與老師通行碼
- [ ] 執行 `python -m pytest`，全部通過

## 身分（participant-access）
- [ ] 錯誤通行碼 → 顯示「通行碼錯誤」
- [ ] 正確通行碼 → 進入老師控制台
- [ ] 學生名字留空 → 顯示「請輸入名字」
- [ ] 分頁 B 加入第 1 組、分頁 C 加入第 2 組；老師頁「各組成員」出現兩人
- [ ] 重新整理學生分頁，仍是原本的組別與名字
- [ ] 老師把組數改成 6 → 新開的加入頁可選到第 6 組

## Guided Notes（guided-notes）
- [ ] 上傳 `samples/sample-group.xlsx` → 顯示共 5 題，第 3、5 題為題組
- [ ] 上傳 `samples/sample-moved.xlsx` → 顯示共 3 題，位置在不同工作表（證明非固定位置）
- [ ] 用**老師提供的範本**複製一份，在填空格加上 `{{1}}`、`{{2}}`… 後下載 xlsx 上傳 → 題數與範本一致
- [ ] 把上述 Google Sheets 設為「知道連結的人皆可檢視」，用網址匯入 → 成功
- [ ] 上傳一份沒有佔位符的試算表 → 顯示錯誤，原題目不變

## 搶答（buzzer-activity、live-sync）
- [ ] 開啟搶答前學生的作答欄是灰色不能輸入
- [ ] 老師按「開啟搶答」→ 兩個學生分頁幾乎同時變「搶答中」
- [ ] 第 2 組先送第 1 題、第 1 組後送 → 老師頁第 1 題顯示第 2 組成功、第 1 組順位 2
- [ ] 第 1 組分頁上**看不到**第 2 組的任何答案或送出狀況
- [ ] 同一組另開一個分頁（同組另一位成員）→ 看得到本組已送出的答案；再送同一題被拒絕
- [ ] 送出空白答案被拒絕；題組只填一格被拒絕
- [ ] 老師按「結束搶答」→ 學生頁同步顯示結果與各組成功題數；作答欄消失
- [ ] 結束後學生再送出（例如用另一個未送出的題）→ 不可能／被拒絕

## 匯出（guided-notes、result-reporting）
- [ ] 匯出 Guided Notes → 用 Excel 或上傳 Google Sheets 打開，成功答案寫在原本的填空格，其他文字與格式不變，沒人答的題目仍是 `{{n}}`
- [ ] 在 Google Sheets「檔案 → 匯入 → 取代試算表」放回原檔 → 內容正確
- [ ] 匯出 CSV → 用 Excel 打開中文正常，欄位：題號、小題、組別、答案、搶答順位、是否成功、送出秒數

## 公平模式（額外功能）
- [ ] 按「重設」，勾選公平模式、時間窗 5 秒並儲存
- [ ] 讓第 1 組先搶下 2 題；之後某題第 1 組先送、第 2 組在 5 秒內送 → 第 2 組成功
- [ ] 同上但第 2 組超過 5 秒才送 → 第 1 組成功
