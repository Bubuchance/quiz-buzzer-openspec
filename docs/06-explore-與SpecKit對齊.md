# 06 Explore 紀錄：與 SpecKit 組功能對齊

> 依老師流程圖「已歸檔後若要新增或修改功能，回 Explore 開新的 Change」。
> 來源：SpecKit 組提供的 `docs/speckit/features.md` 與 `docs/speckit/feature-alignment-原始版.md`。
> 作業規定「兩個小組產出的系統功能要一致」，因此以 SpecKit 組的行為規則為準調整本組系統。

## 使用的提示詞

```text
/openspec explore
請比對 docs/speckit/features.md、docs/speckit/feature-alignment-原始版.md 與目前 openspec/specs/ 的主規格，
列出兩組行為不一致之處、需要新增的功能，以及「待雙方確認」項目的建議做法。本次只討論，不寫程式。
```

## 差異比對

| 項目 | 本組原本 | SpecKit 組規則 | 處理 |
|------|----------|----------------|------|
| 活動階段 | 未匯入、等待開始、搶答中、已結束（4 個） | 準備中 → 搶答中 → 已結束（3 個） | **改**：畫面只顯示 3 個階段；未匯入題目也算「準備中」 |
| Guided Notes 定位 | 儲存格內的 `{{n}}` 佔位符 | 依欄位標題「題號」「作答」動態定位，標題列不一定在第一列、欄位順序可能不同 | **改** |
| 題組標示 | `{{n-k}}` | 作答欄以（1）（2）…標示，分布在相連多列，後續列題號欄為空 | **改** |
| 匯出未作答的題 | 保留佔位符 | 該格保持空白 | **改**（單題原本就是空白格；題組保留原（k）標示） |
| 公平模式 | 時間窗內成功題數少者優先 | 有效時間 = 收到時間 + 已成功題數 × 延遲量；順位依有效時間排序 | **改** |
| CSV 欄位 | 題號、小題、組別、答案、搶答順位、是否成功、送出秒數（題組每格一列） | 題號、組別、答案、搶答順位、是否搶答成功、送出時間（每筆一列） | **改** |
| 倒數計時 | 無 | 老師設定時限，時間到自動結束 | **新增** |
| 老師標記對錯＋計分板 | 只有成功題數統計 | 老師手動標記對錯，累計得分 | **新增**（保留成功題數一起顯示） |
| 學生作答進度 | 無 | 顯示「本組已送出 N / 總題數」 | **新增** |
| 老師密碼、第 N 組、送出鎖定、不判對錯、隱藏他組、重連回到原組別 | 已一致 | — | 不變 |

## 「待雙方確認」本組的建議（需回覆 SpecKit 組）

| 項目 | 本組建議 | 理由 |
|------|----------|------|
| Google Sheets 讀寫與授權 | **不用 API**：匯入可上傳 .xlsx，或貼「知道連結的人皆可檢視」的網址；匯出下載 .xlsx 再到 Google Sheets「檔案 → 匯入 → 取代試算表」 | 不需要任何金鑰或 OAuth，最符合「不可洩漏金鑰」；助教拿到 repo 不用設定憑證就能測 |
| CSV 欄位 | 採用 SpecKit 版：題號、組別、答案、搶答順位、是否搶答成功、送出時間。題組答案合併成「（1）A（2）B」一格；送出時間格式 `YYYY-MM-DD HH:MM:SS.mmm` | 一筆送出一列，與 SpecKit 文件一致 |
| 公平順位公式與延遲量 | 公式照 SpecKit 版。「已成功題數」在**伺服器收到該答案的當下**計算（用當時的暫定結果），之後不再變動；延遲量 1–30 秒，**預設 3 秒** | 收到時就固定有效時間，結果可重現、學生好理解 |
| 組別數量與命名 | 第 N 組，預設 4 組，上限 20 組 | 一般課堂組數足夠 |
| 老師密碼設定 | 環境變數 `TEACHER_PASSCODE`；沒設定就在啟動時隨機產生並只顯示在終端機 | 不進 repo |
| 創意功能兩組都做嗎 | **都做**，規則如下 | 作業要求兩組功能一致；SpecKit 組已規劃 |
| 倒數計時細節 | 時限 0–3600 秒，0 表示不限時；在準備中設定，開啟搶答時開始倒數 | — |
| 標記對錯細節 | 已結束後，老師對每題的成功答案標記「對／錯／未標記」；每個「對」得 1 分；重設或重新匯入時清除 | — |
| 計分板 | 依得分排序，同分再比成功題數，再比組別編號 | — |

## 驗收情境（寫進新的 spec）

1. 標題列在第 4 列、欄位順序為「作答｜題目｜題號」的學習單可正確匯入。
2. 題組第 3 題佔兩列：「3｜…｜（1）」「（空）｜…｜（2）」→ 辨識為題組 2 小題。
3. 找不到「題號」「作答」標題 → 錯誤訊息，不改變原題目。
4. 匯出：單題答案寫入作答格；題組各小題答案寫入（1）（2）所在格；無人作答的單題保持空白。
5. 公平模式延遲 3 秒：第 1 組已成功 2 題，在 10.0 秒送出；第 2 組 0 題，在 15.0 秒送出 → 有效時間 16.0 vs 15.0，第 2 組成功且順位第 1。
6. 倒數 60 秒：時間到伺服器自動結束搶答，所有畫面同步變「已結束」。
7. 學生頁顯示「本組已送出 2 / 5 題」，不顯示他組任何資訊。
8. 已結束後老師把第 1 題標「對」→ 計分板該組 +1 分，學生頁同步看到。
9. CSV 欄位為 SpecKit 版 6 欄。
