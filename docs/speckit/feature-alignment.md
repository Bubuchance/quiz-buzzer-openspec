## 2. 必須一致的行為規則

### 角色與階段（001）
- 兩種使用者：老師（以老師密碼進入）、學生（進入後選擇組別「第 N 組」）。
- 活動階段固定三個：**準備中 → 搶答中 → 已結束**，由老師切換，所有使用者畫面即時同步。
- 學生重新整理或斷線重連後，回到目前階段與所屬組別。

### 匯入/匯出（002）
- 學習單為 Google Sheets 格式。
- 依欄位標題「**題號**」「**作答**」動態定位，**不可寫死儲存格位置**（助教會用另一份學習單測試）。標題列不一定在第一列，欄位順序可能不同。
- 匯入只取題號與題數，不需題目敘述；題數必須與學習單一致。
- 匯出：活動結束後，把每題「搶答成功組別的答案」寫回該題在作答欄的對應儲存格；無人作答的題，該格保持空白；不破壞其他內容。

### 搶答與判定（003）
- 搶答開始後，學生以組別為單位送出答案。
- 每組每題**只有一筆有效答案，送出後鎖定**；不允許空白答案。
- 以**伺服器收到時間**最早的組別為搶答成功；**不判斷答案對錯**（學習單沒有標準答案）。
- 同組多人時，任何一位成員先送出即代表該組。
- 搶答結束前，學生看不到其他組別的作答內容與狀況；老師可即時看到各題作答狀況。
- 結束後學生可看到每題的成功組別、答案與自己組的結果。

### 題組（004）
- 一個題號含多個填空，在作答欄以（1）（2）… 佔位符標示，分布於相連多列（後續列的題號欄為空）。
- 題組必須**全部填完才能同時送出一次**，以該次送出時間計算順位。
- 匯出時，各子題答案寫回各自的佔位符儲存格。
- 單題與題組可混合在同一份學習單。

### 結果匯出 CSV（005）
- 每筆資料一列，欄位（建議，請雙方確認）：**題號、組別、答案、搶答順位、是否搶答成功、送出時間**。

### 公平順位機制（005）
- 老師可選擇開啟，**預設關閉**；關閉時嚴格依收到時間。
- 開啟時：有效時間 = 收到時間 + 已搶答成功題數 × 延遲量（延遲量由老師設定）。
- 順位依有效時間排序。

### 創意功能（006，若兩組都做）
- 倒數計時：老師設定時間限制，時間到自動結束搶答。
- 老師標記對錯與計分板：結果檢視時老師手動標記對或錯，累計各組得分；系統不自動判斷。
- 學生端作答進度提示：顯示「本組已送出 N / 總題數」，不揭露他組內容。

## 3. 待雙方確認（OpenSpec 組的建議）

- [ ] **Google Sheets 讀寫與授權方式**（**依 11-17 課程公告更新**：必須直接串接雲端 Google Sheets 讀寫，不能下載 xlsx 離線處理）：OpenSpec 組改用 **Google Sheets API ＋ 服務帳號**。
  - 老師把學習單「共用」給服務帳號 email（編輯者），貼上試算表網址匯入；結束後按「寫回 Google Sheets」直接寫入雲端。
  - 金鑰 JSON 放本機 `credentials/`（`.gitignore` 排除），路徑可用環境變數指定，不進 repo。
  - 寫回前重新讀取試算表，題目結構被改過就拒絕寫回。
  - 建議 SpecKit 組也用 API 直接讀寫（服務帳號或 OAuth 皆可），行為一致即可。
- [ ] **CSV 欄位與順序**：同意第 2 節的 6 欄與順序。補充細節：
  - 每筆送出一列（同一題有幾組送出就有幾列）。
  - 題組答案合併成一格：「（1）答案（2）答案」。
  - 是否搶答成功：填「是／否」。
  - 送出時間格式：`YYYY-MM-DD HH:MM:SS.mmm`（伺服器本機時間）。
- [ ] **公平順位的公式與延遲量預設值**：公式同第 2 節。補充：
  - 「已搶答成功題數」在**伺服器收到該答案的當下**計算（依當時的暫定結果），之後不再改變。這樣有效時間收到就固定，結果可重現。
  - 延遲量範圍 1–30 秒，**預設 3 秒**。
  - 有效時間相同時，以收到先後決定。
- [ ] **組別數量與命名**：「第 N 組」，預設 4 組，老師可設定 1–20 組。
- [ ] **老師密碼的設定方式**：環境變數 `TEACHER_PASSCODE`；未設定時啟動時隨機產生 6 位數，只顯示在終端機。
- [ ] **要不要兩組都做 🟨 創意功能**：建議都做（OpenSpec 組已完成）。細節：
  - 倒數計時：時限 0–3600 秒，0 = 不限時，預設 0；在準備中設定，開啟搶答時開始倒數。時間到之後收到的答案一律拒絕。
  - 標記對錯：只在「已結束」後可標記；只能標記有成功組別的題目；可改標或取消；每個「對」得 1 分；重設或重新匯入時清除。
  - 計分板：依得分排序，同分比成功題數，再比組別編號；學生在結束後也看得到。
  - 作答進度：只在搶答中顯示，N = 本組已送出的題數（題組算 1 題）。

### 另外需要統一的小細節

- 學習單題號欄格式：OpenSpec 組接受 `3`、`3.`、`第3題`；題號欄非數字的列（段落標題）略過。
- 題組佔位符：接受全形「（1）」與半形「(1)」。
- **寫回格式（更新）**：題組小題寫成「（1）答案」——保留（k）標示、答案接在後面，這樣寫回後的試算表仍可再次匯入、再次寫回；沒人作答的題組只留（k）。單題寫入答案，沒人作答寫入空白（重設後再玩一輪不會殘留舊答案）。
- 寫回時機：搶答「已結束」後才能寫回。
- 使用第一個含「題號」「作答」標題列的工作表。
- 重設：已結束後老師可「重設」清除作答與標記、保留題目，回到準備中再玩一輪。
