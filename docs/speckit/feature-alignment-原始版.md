# 搶答系統 功能對齊清單（SpecKit 組 ⇄ OpenSpec 組）

用途：確認兩組做出來的系統行為一致。技術棧、介面設計、程式語言各組自由，**下列行為規則必須相同**。有想改的地方，請先在群組討論，雙方同意後更新本清單。

標註：🟦 核心（規定必做）　🟩 額外（說明列出的選項）　🟨 創意（本組自行構想）

## 2. 必須一致的行為規則

### 角色與階段（001）
- 兩種使用者：老師（以老師密碼進入）、學生（進入後選擇組別「第 N 組」）。
- 活動階段固定三個：**準備中 → 搶答中 → 已結束**，由老師切換，所有使用者畫面即時同步。
- 學生重新整理或斷線重連後，回到目前階段與所屬組別。

### 匯入/匯出（002）
- 學習單為 Google Sheets 格式。
- 依欄位標題「**題號**」「**作答**」動態定位，**不可寫死儲存格位置**（助教會用另一份學習單測試）。標題列不一定在第一列，欄位順序可能不同。
- 匯入只取題號與題數，不需題目敘述；題數必須與學習單一致。
- 匯出：活動結束後，把每題「搶答成功組別的答案」寫回該題在作答欄的對應儲存格；無人作答的題，該格保持空白；不破壞其他內容。

### 搶答與判定（003）
- 搶答開始後，學生以組別為單位送出答案。
- 每組每題**只有一筆有效答案，送出後鎖定**；不允許空白答案。
- 以**伺服器收到時間**最早的組別為搶答成功；**不判斷答案對錯**（學習單沒有標準答案）。
- 同組多人時，任何一位成員先送出即代表該組。
- 搶答結束前，學生看不到其他組別的作答內容與狀況；老師可即時看到各題作答狀況。
- 結束後學生可看到每題的成功組別、答案與自己組的結果。

### 題組（004）
- 一個題號含多個填空，在作答欄以（1）（2）… 佔位符標示，分布於相連多列（後續列的題號欄為空）。
- 題組必須**全部填完才能同時送出一次**，以該次送出時間計算順位。
- 匯出時，各子題答案寫回各自的佔位符儲存格。
- 單題與題組可混合在同一份學習單。

### 結果匯出 CSV（005）
- 每筆資料一列，欄位（建議，請雙方確認）：**題號、組別、答案、搶答順位、是否搶答成功、送出時間**。

### 公平順位機制（005）
- 老師可選擇開啟，**預設關閉**；關閉時嚴格依收到時間。
- 開啟時：有效時間 = 收到時間 + 已搶答成功題數 × 延遲量（延遲量由老師設定）。
- 順位依有效時間排序。

### 創意功能（006，若兩組都做）
- 倒數計時：老師設定時間限制，時間到自動結束搶答。
- 老師標記對錯與計分板：結果檢視時老師手動標記對或錯，累計各組得分；系統不自動判斷。
- 學生端作答進度提示：顯示「本組已送出 N / 總題數」，不揭露他組內容。
